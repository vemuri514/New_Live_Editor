HOW TO RUN ON LOCALHOST:8080

1. Unzip this folder.
2. Windows: double-click start-server.bat
   Mac/Linux: open a terminal in this folder and run: sh start-server.sh
   Or manually: python -m http.server 8080   (python3 on Mac/Linux)
3. Open http://127.0.0.1:8080 or http://localhost:8080 in your browser.
4. Press Ctrl+C in the terminal to stop the server.

Python must be installed (python.org). Internet is needed because the editor
library (CodeMirror) loads from cdnjs.
